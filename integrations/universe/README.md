# Universe: The Megatrend Selection

**Objective:** Define the "God List" of tradable assets based on the 3 Pillars of *Investire nei megatrend del futuro*.

## The 3 Pillars

1.  **Demographics (Silver Economy & New Middle Class)**
    -   *Keywords:* BioTech, Pharma, Luxury, Travel.
    -   *Assets:* Stocks/ETFs (if supported), or Crypto Proxies (e.g., RWA tokens).

2.  **Technology (AI & Connectivity)**
    -   *Keywords:* AI, Cloud, 5G, IOT.
    -   *Crypto Assets:* RNDR (Compute), FET (AI), SOL (Speed), LINK (Oracle).

3.  **Environment (Energy Transition)**
    -   *Keywords:* Solar, Batteries, EV.
    -   *Crypto Assets:* POWR (Energy), ALGO (Carbon neutral).

## Protocol
The file `universe.json` (to be created) will control the `allowed_symbols` in the Rust Engine.
